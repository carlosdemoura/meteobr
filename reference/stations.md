# Additional information about INMET's automatic stations

Additional information about INMET's automatic stations

## Usage

``` r
stations
```

## Format

### `stations`

A data frame with 624 rows and 9 columns:

- station.id:

  INMET's id of the station

- station.name:

  original name of the station on INMET's website

- lat:

  latitude of the station (meters)

- lon:

  longitude of the station (meters)

- alt:

  altitude of the station (meters)

- foundation:

  date station was founded

- town.id:

  IBGE code for station's town

- town.name:

  name of the town in which station is located, according to IBGE

- state:

  state in which the station is located

- region:

  national region in which the station is located
